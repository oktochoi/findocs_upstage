# 슬기짜기2 · 금융 서류 민감정보 위험도 판정

Upstage AI Agent 해커톤 V.2 iM뱅크 지정주제 트랙("AI 기반 금융문서 민감정보 자동 식별 및 위험도 등급화") 슬기짜기2 팀의 최종 제출 저장소입니다.

은행 영업점 직원이 고객 서류 PDF를 외부 AI 서비스나 외부 기관으로 보내기 전에 점검하는 Upstage Studio 워크플로우를 만들었습니다. PDF를 넣으면 위험 등급(매우 높음·높음·보통·없음), 사람이 원본을 다시 봐야 하는지(검토 필요), 가릴 칸 목록, 조치를 냅니다. 서류에서 값을 읽는 일은 모델이 하고, 등급과 검토 필요는 Validate 규칙이 정합니다.

## 지킬 것

- 공개 저장소입니다. API 키는 `.env`에만 두고 커밋하지 않습니다.
- 판정은 Studio 워크플로우 안에서만 합니다. 웹 코드는 워크플로우를 부르고 결과를 보여 주기만 합니다.
- 데이터셋 서류의 값은 모두 지어낸 가상의 값입니다. 실제 개인정보가 든 서류는 올리지 않습니다.
- 데이터셋 PDF와 zip은 iM뱅크 서식자료실 서식에 값을 채운 것이고, 다시 배포해도 된다는 허락을 확인하지 못해 저장소에 올리지 않습니다(`.gitignore`). 받은 PDF는 `제출물/데이터셋/`에 두면 커밋되지 않습니다.
