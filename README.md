# 슬기짜기2 · 금융 서류 민감정보 위험도 판정

Upstage AI Agent 해커톤 V.2에 iM뱅크 지정주제 트랙으로 참가한 슬기짜기2 팀의 최종 제출 저장소입니다. 트랙 주제는 "AI 기반 금융문서 민감정보 자동 식별 및 위험도 등급화"입니다.

은행 영업점 직원이 고객 서류 PDF를 외부 AI 서비스나 외부 기관으로 보내기 전에, 그 서류에 개인정보가 얼마나 드러나 있는지 점검하는 Upstage Studio 워크플로우를 만들었습니다. PDF를 넣으면 위험 등급(매우 높음·높음·보통·없음), 사람이 원본을 다시 봐야 하는지(검토 필요), 가려야 할 칸 목록, 직원이 할 조치를 냅니다. 서류에서 값을 읽는 일은 AI 모델이 하고, 등급과 검토 필요는 Validate 규칙이 정합니다. Validate는 LLM을 쓰지 않고 정규식·값 비교 같은 조건으로 앞 노드 결과를 검사하는 Studio 노드입니다.

## 지킬 것

- 이 저장소는 공개 저장소입니다. 그래서 API 키는 `.env`에만 두고, `.env`는 커밋하지 않습니다.
- 판정은 Studio 워크플로우 안에서만 합니다. 웹 코드는 워크플로우를 부르고 결과를 보여 주기만 합니다.
- 데이터셋 서류의 값은 모두 지어낸 가상의 값입니다. 이 데이터셋 말고 실제 개인정보가 적힌 서류는 저장소에도 워크플로우에도 올리지 않습니다.
- 데이터셋 PDF는 iM뱅크 서식자료실의 서식에 값을 적어 만든 서류입니다. 그런데 이 서식을 다시 배포해도 된다는 허락을 확인하지 못해서, PDF와 이를 묶은 zip은 저장소에 올리지 않고 `.gitignore`에 적어 두었습니다. 그래서 팀 채널로 받은 PDF를 `제출물/데이터셋/`에 두어도 커밋되지 않습니다.
